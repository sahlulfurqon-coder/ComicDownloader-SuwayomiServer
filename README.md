# ComicDownloader-SuwayomiServer
This project was created to download manga resources per chapter from a Github project called "Suwayomi" with the help of Google Drive as download storage and Cloudflare as the server tunnel, Flaresolver is used to penetrate anti-bot protection from Cloudflare and DDoS-GUARD (Use Wisely)

Note: after successfully running the cloudflare server to open Suwayomi, click browse and add the following extension https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.json
